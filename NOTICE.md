# zoom-studio

This repository is a fork of [mungewell/zoom-zt2](https://github.com/mungewell/zoom-zt2)
(MIT License, Copyright (c) 2019 mungewell). The original scripts at the repository root are
kept unchanged; the new Qt application lives in `zoomstudio/`.

The upstream author does not accept AI-generated contributions (see `ai.md`). This fork is
developed with AI assistance, so none of its changes are proposed upstream.

## Bundled fonts

`zoomstudio/ui/design/fonts/` ships two font families with their licences:

- **Exo 2** (`Exo2-Variable.ttf`, one file with every weight, `OFL.txt`): Copyright 2013 The Exo 2 Project Authors
  (https://github.com/googlefonts/Exo-2.0), SIL Open Font License 1.1. Obtained from the Google Fonts
  repository (`ofl/exo2`).
- **Roboto** (`Roboto-Regular.ttf`, `Roboto-Medium.ttf`, `Roboto-Bold.ttf`, `LICENSE-Roboto.txt`):
  Copyright 2011 Google Inc., Apache License 2.0.
